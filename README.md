# HireTrack 🚀

HireTrack is a MERN stack based Job Application and Interview Tracking platform.

It helps users manage job applications, track application status, schedule interviews, manage resume versions, and view application analytics from one dashboard.

## ✨ Features

- 🔐 User Registration & Login
- 🛡️ JWT Authentication
- 💼 Add, Edit & Delete Job Applications
- 🔎 Search & Filter Jobs
- 📊 Application Analytics Dashboard
- 🎯 Interview Tracking
- 🕐 Interview Date & Time
- 💻 Online / Offline / Phone Interview Type
- 🔗 Interview Meeting Links
- 📄 Resume Version Tracking
- 📈 Resume Usage Analytics
- 📱 Responsive Design

## 🛠️ Tech Stack

### Frontend

- React.js
- React Router
- Axios
- Recharts
- CSS

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcryptjs
